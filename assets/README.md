# Casa-Lumi — portada visual

Esta versión agrega una portada fiel a la ilustración de referencia, sin sustituir tu aplicación existente.

## Instalación en GitHub

1. Sube la carpeta `assets` (o solo `assets/casa-lumi-referencia.png`) a la raíz de Casa-Lumi.
2. Sube `portada.html` y `portada.css` a la raíz.
3. Abre `https://jasseliot-prog.github.io/Casa-Lumi/portada.html`.
4. Si quieres que esta portada sea el Inicio principal, primero haz una copia de tu `index.html`; después podemos integrar el diseño en tu código actual.

La imagen contiene textos y botones dibujados: los enlaces transparentes se posicionan sobre la ilustración. El diseño se escala proporcionalmente. No hay movimiento articulado todavía.
